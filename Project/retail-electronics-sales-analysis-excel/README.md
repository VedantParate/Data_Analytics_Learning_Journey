**Retail Electronics Sales Analysis -- Excel Dashboard**

**📊 Project Overview**

This project analyzes retail electronics sales data using Microsoft
Excel.

The objective is to validate and clean the dataset, perform sales and
profitability analysis, and build an interactive dashboard for business
insights.

**🎯 Project Objectives**

Perform data quality and validation checks

Identify and handle missing and invalid values

Create cleaned and analysis-ready data

Calculate sales, profit, discount, and margin metrics

Analyze sales across categories, regions, payment methods, customer
types, and order status

Build an interactive Excel dashboard using PivotTables, PivotCharts,
Slicers, and Timeline

Create dynamic KPIs that respond to dashboard filters

**🗂️ Workbook Structure**

Sheet                  Purpose

01_Raw_Data          Original dataset kept untouched
02_Data_Validation   Data quality checks and validation flags
03_Cleaned_Data      Cleaned data and calculated fields
04_Dashboard         Interactive sales dashboard
05_KPI_Pivot         PivotTable supporting dynamic KPI calculations

**🧹 Data Quality & Cleaning**

The project includes validation for:

Missing values

Invalid quantity values

Invalid discount percentages

Missing/invalid customer ratings

Missing payment methods

Delivery-day applicability

Duplicate Transaction IDs

Order-status validation

Invalid or missing values were handled in the cleaned data layer,
while the original raw data was preserved.
